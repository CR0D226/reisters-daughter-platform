# The Reister's Daughter Digital Platform

Modern web and mobile platform for The Reister's Daughter café and bakery.

## Technology Stack

- Vue 3
- TypeScript
- HTML5 / CSS3
- ASP.NET Core
- REST APIs
- React Native
- Optimizely CMS
- Microsoft Azure
- Azure Entra External ID
- OAuth 2.0 / OpenID Connect
- JWT
- Docker
- GitHub Actions
- Bicep

## Project Structure

- `web/` - Vue 3 + TypeScript web application
- `api/` - ASP.NET Core REST API
- `mobile/` - React Native mobile application
- `infrastructure/` - Azure infrastructure and DevOps
- `docs/` - Architecture and technical documentation
